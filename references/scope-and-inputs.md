# 适用范围、输入和开工条件

## 适用范围

| 类型 | 适用的任务 | 条件与边界 |
| --- | --- | --- |
| 城市、文旅、园区 | 地标风光、交通、产业印象、形象预热 | 使用可核实地点的素材；不保证能取得任意景点的航拍/现场视频 |
| 企业、品牌、产品 | 品牌片、产品亮点、制造研发、服务介绍 | 需要可靠卖点与实际素材；设备运动、人物表演和产品手感不由照片动画代替 |
| 会议、展会、活动 | 预热、主题发布、日期与报名信息 | 日期、主题、地点和组织信息可核实；未来会议不用旧现场冒充本届现场 |
| 项目、成果、数据 | 项目发布、阶段成果、短数据展示 | 数据有来源；少量图表可配合镜头，不把复杂数据论证压成空泛口号 |
| 课程、招生宣传 | 课程亮点、活动招募的短广告 | 适合宣传包装，不承担完整长课程教学剪辑 |
| 已有短片修改 | 字幕、字体、构图、署名、节奏、光效、配音/BGM | 读取已有工程与用户改动；小修只改相应对象 |
| 用户素材剪辑 | 自拍/现场/录屏视频、照片、录音混剪成宣传短片 | 可筛选取段、重排、裁切、调速与原声混音；保留原件并记录源入出点，见[剪辑规则](user-media-editing.md) |

通常最适合30—90秒、一条主线、素材驱动的短片；10秒片头或更长片段并非技术上禁止，按信息量与交付目标判断。支持横屏、竖屏和方形，不把1080P横屏固定为所有任务要求。

长访谈、完整纪实片、长课程、剧情、真人UGC表演、复杂三维镜头或纯转录不由本技能作为主流程。若用户要整片，先说明需要长素材整理、转录/说话人辨识、剪辑决策和连续性处理；本技能可接其中的片头、标题、图文包装或单独预告。不得声称渲染器不能输出长视频，边界是本技能未覆盖这些编辑工作。

## 输入分级

**启动策划所需：**一个宣传主题或对象即可。只有主题时，先代拟2—3个可选方向并推荐一个，给出待确认的需求卡；不把核心卖点、素材或完整脚本作为启动门槛。需要观众记住的核心信息/行动在需求关共同确定，不能自行编造产品功能、数据或会议事实。受众、平台、画幅、时长已有上下文就沿用；缺少时只询问影响结果的关键项，其余提出建议供本关确认。

支持三种入口：主题起步（从方向和取材开始）、自有素材（盘点后剪辑）、混合素材（优先现有材料，按具体缺口补充）。这些入口共用同一套逐关流程。

**用户可选提供：**logo/品牌规范、照片视频、旁白或录音、参考片、音乐、数据与事实资料、已有工程、精确署名。没有自有素材不是拒绝开工的理由。

用户提供的素材可直接作为剪辑来源；不默认上网替换或生成新图，也不把已有录音自动认定为最终旁白。取较长素材的部分片段做独立预告可在本技能范围内，整部长片的叙事编辑仍按前述边界处理。

**最终渲染必须具备：**

- 可读取且用途许可明确的实际媒体与字体，内容符合用户真实/生成素材偏好。
- 已锁定的文字、画幅、时长；有配音时有最终录音和时间点，有字幕时有统一文本。
- 引导模式下，需求、文案、分镜与素材、样片已按[逐关引导](guided-stages.md)通过；用户明确授权自动推进时按其范围执行。
- 所选引擎、项目依赖、浏览器和编码工具可用；文件规格验收还需相应检查工具。
- 必须使用的账号/凭据仅在用户选定相应外部服务时才成为条件。

用户只要BGM：不要求旁白、TTS或口播字幕，标题仍可作为画面文字。用户要无声：不要求音乐和音轨。用户没有指定署名：不继承深圳示例的个人账号或活动名。

用户只要交互预览时，以可运行的预览为交付条件，不额外要求MP4编码、ffprobe或Python检查器。浏览器及预览实际使用的媒体处理工具仍需可用；以后要求视频文件时再补编码与文件验收条件。

## 没有素材时怎么做

1. 用户已说没有素材时直接按主题起步，不反复索要上传。需求关先给方向、建议规格与取材方式，不以找到全部素材为过关条件；可初步查询可获得性以判断方向是否可行，不提前购买或批量下载。
2. 文案确认后，在分镜与素材关列出具体镜头需求和准确地点/主体，检索、筛选并展示可用素材及许可；用户后来补充材料时优先评估。除摄影/视频外，用户认可的生成图或代码图形动画可承担适合的非现场表达。
3. 联网时优先可核实来源的官方媒体页、明确授权素材库或Wikimedia Commons；逐项读来源和许可，官方发布不自动等于可自由宣传使用。
4. 可按预算/账号限制筛选免注册、授权清楚的来源，但不保证任意地点都有免费可用高清素材。排除许可不适配用途的文件。
5. 用户同意生成图时可补充概念性画面并标记来源；“真实现场”要求不能因此降低。
6. 确实缺素材时在已授权的阶段交付文案、分镜、取材清单或可明确识别的占位预览，列出最终片仍缺的项目；不把占位、异地或生成画面伪装成最终实景，也不跳过尚待确认的关卡。

## 离线条件

已有项目的依赖、渲染浏览器、字体、媒体、音轨和必要文档齐全时，可用本地命令继续制作。先检查node_modules和本地CLI，避免npx暗中联网。缺某项时明确限制，完成能做的代码/配置/分镜工作，不因断网改引擎、注册服务或重做用户录音。

无网络且数据来源也未缓存，不能宣称完成最新事实核实。用户录音与新版画面冲突时，保留录音并提出具体冲突，等待用户取舍后再完成依赖该取舍的段落。
