# 与引擎无关的验收

核实表述来源、真实地点、通用图用途和生成图标记；保留摄影、字体与音乐署名和许可。

## 画面

- 查看最终导出开场、密集镜头、高潮、结尾和每次切镜前后，不只看入场结束后的静帧。
- 检查主体裁切、标题长度、字幕位置、字体缺字与光效覆盖，按平台遮挡区留出空间。
- 看版式与镜头尺度是否有变化；阅读和片尾可停留，不因机器报告低运动量而让所有镜头晃动。
- 资源就绪后比较顺播、倒退、直接seek的同一帧；避免将字体加载差异误判成时钟问题。
- 帧差仅找候选异常，人工区分合法切镜、扫光、微粒与闪帧，不追求零硬切。

## 声音

完整试听旁白、音乐、转场；检查句尾切断、音乐抢话、避让抽动、结尾突断。无法试听时明确只做波形/频谱/响度检查。

普通带旁白短片可从约-16 LUFS、真峰值低于-2 dBTP的工程目标开始，按用户和平台修改；不是所有平台强制标准。最终AAC再测，不只测WAV。

```sh
ffmpeg -hide_banner -i final.mp4 -af ebur128=peak=true:framelog=verbose -f null NUL
```

Windows使用NUL，类Unix可用/dev/null。

## 文件

ffprobe确认尺寸、帧率、片长与音轨，字幕不越界；母带不重复混音。工程交付区分两种形式：独立包包含可合法打包的素材、字体、配置、源代码、锁文件与使用说明，解压后不依赖旧文件夹；用户选择引用原件时，交引用式工程，列清外部路径、缺项和重链接方法，不宣称可直接移机运行。受许可限制的媒体/字体不擅自再分发。说明依赖安装要求，不把未含依赖的包称为完全离线即开即用。

scripts/check_delivery.py检查元数据、SRT与可选响度；不检测缺字、画面真假、闪帧，不代替观看。
