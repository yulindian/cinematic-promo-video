# 深圳 APEC 工程拆解

依据45秒v5工程与本次会话，区分“工具提供”与“实际使用”。原工程和媒体不随新技能复制。

| 原功能 | 本次使用 | 独立替代 |
| --- | --- | --- |
| studio | 本地预览 | HyperFrames preview / Remotion Studio |
| render | 逐帧捕获编码 | 引擎官方导出 |
| still | 关键帧抽取与人工审阅 | 原生快照＋最终MP4抽帧 |
| check | 文件、布局、跳转一致性 | 原生检查＋实际画面审阅 |
| qa | 帧突变、停留、运动分析 | 最终视频切点/帧分析＋人工区分闪帧与合法切镜 |
| OM.vars | 文案、日期、署名变量 | 本地配置 / React props |
| OM.clock | 按时间驱动Canvas | 纯drawFrame(time)接入引擎时钟 |
| 时间轴注册与根属性 | 暂停GSAP时间轴、片长 | HyperFrames原生契约 / Remotion Composition与Sequence |
| 字体与运行资源 | 部分字体、本地资源 | 独立字体及各自许可，不复制om.js |
| sound、OM.music/sfx、ABC | 早期用过，最终由独立母带替换 | 授权音乐＋Python/FFmpeg与自制音效，无需迁移ABC作曲器 |
| voice | 实际配音由Edge TTS和自写脚本生成 | 独立TTS/录音及时间点 |
| learn add/harvest | 偏好保存与回顾 | 项目brief与偏好配置，无需重建全局记忆产品 |
| inbox/look/done、模板目录、云服务 | 不在本次必需执行链 | 不纳入最小功能 |

## 能保留的内容

旁白、音频、SRT、摄影与字体及许可；配色、排版、镜头顺序、语义落点；自写的镜头运动、纯函数粒子/扫光算法、混音和低鼓/掠过音效。

## 必须适配的部分

- 去除旧运行时与变量/时钟接口。
- 旧工程由JS创建场景，HyperFrames需要适配原生可编辑片段结构，不能只换命令。
- 旧autoAlpha场景控制不能原样放到HyperFrames管理生存区间的clip上；淡入淡出放在子层。
- Remotion需改React挂载、局部帧和Canvas重绘；其GSAP hook不承接旧对象代理时钟。
- lint、视觉检查和闪帧判断是不同工作，不能互相冒充。

## 合适定位

城市文旅、企业品牌、会议活动、项目发布、成果展示等素材驱动短片，常见30—90秒，实际画幅与时长由用户决定。人物剧情、长访谈和长课程需补充专门剪辑流程。

45秒、蓝金色、中文男声、无字幕句末标点、具体署名都是本项目设置，不成为所有题材的固定限制。
