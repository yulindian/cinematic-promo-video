# 用到哪些东西

本技能是制作流程与判断规则，不自带完整视频软件、媒体库、字体、浏览器或云端账号。依赖装在当前视频项目，不在技能目录内建立共用运行环境。

## 核心工具

| 内容 | 用途 | 是否必需 |
| --- | --- | --- |
| HyperFrames或Remotion | 预览、时钟、静帧、视频输出 | 选一个；已有工程沿用其引擎 |
| Node.js与项目包管理器 | 运行所选引擎、锁定依赖 | 代码渲染路线需要；HyperFrames当前文档要求Node 22以上，Remotion按锁定版本要求 |
| Chrome/Chromium | 浏览器画面渲染 | 引擎路线需要；先复用可用安装或已缓存的渲染浏览器 |
| FFmpeg | 视频取段/转码、音轨提取、代理预览、混音、频谱/响度分析 | 本地媒体处理按需使用；安装方式按引擎与机器环境，不先转码所有用户原片 |
| ffprobe | 读取尺寸、帧率、片长、音轨 | 附带交付检查脚本需要 |
| Python | 运行附带检查器、按需编写媒体辅助脚本 | 检查器路线需要；不是HTML/React动画运行时 |
| 图片、视频、字体 | 构成实际画面 | 成片需要合适素材与字体；许可证分别保留 |

HyperFrames接口见 [HyperFrames说明](hyperframes.md)，React/帧驱动接口见 [Remotion说明](remotion.md)。只安装当前项目选择的引擎，不为双引擎支持同时下载两套工具。

按交付阶段检查依赖：交互预览需要引擎、项目依赖、浏览器与实际预览素材；导出还需要引擎适用的编码能力；本技能的文件验收脚本需要Python和ffprobe，响度分析再调用ffmpeg。缺ffprobe不会单独阻止纯预览任务，也不能据此宣称已完成视频文件规格检查。

## 按需工具与服务

| 可选项 | 使用时机 | 不需要的情况 |
| --- | --- | --- |
| GSAP | 复杂DOM/SVG镜头运动；HyperFrames常用 | Remotion可直接用帧函数，无需强制加GSAP |
| Canvas | 固定种子的粒子、扫光等自写光效 | 纯照片运动与排版可不使用 |
| Edge TTS或其他语音服务 | 用户需要配音且未提供最终录音 | 纯BGM、无声视频或已有用户录音 |
| 字幕识别/对齐工具 | 从用户录音或视频原声获取台词与时间点 | 已有可靠时间点、无讲话或无需字幕；识别结果须核对 |
| 图像生成工具 | 用户允许概念画面、补充非现场视觉 | 只允许真实摄影的项目 |
| Python的Pillow、NumPy | 联系图、像素分析、程序音效与特定混音脚本 | 附带check_delivery.py只用标准库，不要求这两个包 |
| 浏览器录制/屏幕采集 | 产品界面需要真实操作展示 | 已有适合素材的普通宣传片 |
| 云端渲染/模型API | 用户选用该服务且资源可用 | 本地渲染不默认要求HeyGen、TTS或生图付费账号 |

TTS、生成图和云服务分别处理凭据与费用，不捆绑为必选服务。不声称所有工具、素材和商业用途都免费；核对所选引擎与具体素材许可。已有用户录音不擅自变成新的合成声音。

## 开工检查顺序

1. 读现有package.json、锁文件和项目README；检查本地Node、引擎CLI、浏览器、FFmpeg/ffprobe。依赖已可用就复用，不重装或升级全局环境。
2. 检查媒体路径、文件格式和字体字符覆盖；远程字体或图片需要本地化，离线时缺失项明确标记。
3. 按需检查配音/BGM/字幕是否真的需要、是否已有；只有实际选中的外部服务才检查凭据。
4. 先用短片段验证时钟、中文、Canvas和音轨，之后再渲染整片。

任何必须的依赖缺失时，提供具体缺项和对应安装/配置步骤。仅缺可选项就走用户认可的其他路线，不把“没有TTS账号”解释成“不能做纯BGM视频”。同一网络失败有界重试，不绕过来源限制或反复触发生成费用。

## 独立性与目录

新工具在tools/有自己目录；Node使用自身package.json与锁文件，Python扩展依赖使用自身.venv与清单。技能自带脚本用显式技能路径调用，不从相邻视频工具导入代码或借用其私有环境。

可采用工具根目录下project/存HTML工程、outputs/存交付物、.tmp/存临时文件。HyperFrames临时渲染目录在工具内且project外；这是本次验证过的布局，避免区间渲染复制到自身子目录。已有工程有其他隔离结构时保留其合理约定。

不要把node_modules、.venv、云密钥、真实照片和商业音乐复制进技能发布包。技能可以指导取得/使用素材，但不会因此获得这些素材的再分发权。
